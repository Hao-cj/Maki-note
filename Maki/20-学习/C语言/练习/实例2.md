## <font color="#e36c09">题目</font>：将一个正整数分解质因数。例如：输入 90,打印出 90=2*3*3*5。


## <font color="#ff0000">思路</font>：



## <font color="#00b050">答案</font>：
```c
#include <stdio.h>

#include "../utf8.h"

int main(){

    utf8_console();

    int num=0;

    //输入一个正整数

    printf("输入一个正整数：");

    scanf("%d",&num);

    printf("%d=",num);

    // 开始除

    for (int n=2;num>=n;n++){

        while(num%n==0){

            printf("%d",n);

            num/=n;

            if(num!=1)printf("*");

        }

  

    }
```


>[!success] 输出结果：
>输入一个正整数：90
> 90=2 \*3 \* 3 \* 5
